# Privacy

PALLET has no accounts, analytics SDK, telemetry SDK, cloud storage, automatic update check, or application network feature. Its frontend assets are bundled locally.

This is a source-level statement, not a claim that the packaged process has been network-capture verified on every supported operating system. The operating system, installer, WebView runtime, package manager, and browser used to download PALLET may make their own requests. A release must not make a stronger claim until packaged artifacts have been tested with network capture on each shipping platform.

File-operation history is stored inside the selected warehouse in `.pallet`; it is not sent by PALLET to a service.
